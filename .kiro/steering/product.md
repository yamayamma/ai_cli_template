# Product Overview

TypeScript + GitHub Copilot を活用したWebアプリケーション開発のためのテンプレートリポジトリ。devcontainerによる即座の開発環境構築とSpec-Driven Development（SDD）ワークフローを提供。

## Core Capabilities

- **即時開発環境**: devcontainerで依存関係を含めた開発環境を即座に構築
- **品質自動化**: CI/CD、自動テスト、自動リリースによる品質保証
- **AI支援開発**: GitHub Copilotとの統合、SDD方法論による構造化された開発
- **型安全性**: TypeScript厳格モードによる堅牢なコード品質

## Target Use Cases

- 新規TypeScript/Reactプロジェクトの立ち上げ
- Spec-Driven Developmentワークフローの学習・実践
- AI支援によるチーム開発の標準化

## Value Proposition

- **開発開始までの時間短縮**: devcontainerによりゼロコンフィグで開発開始
- **一貫した品質**: 自動化されたCI/CD、リント、テストによる品質担保
- **構造化された開発**: SDDにより要件→設計→実装の段階的進行を強制
