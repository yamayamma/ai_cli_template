# plan コマンド

仕様に基づいて技術計画と実装戦略を生成します。

## 概要

`plan` コマンドは、仕様と調査結果を分析し、実装に必要な技術計画を生成します。
アーキテクチャ、使用技術、ファイル構造などが含まれます。

## 構文

```bash
speckit plan [options]
```

## オプション

| オプション | 説明 | デフォルト |
|-----------|------|----------|
| `--spec`, `-s` | 対象の仕様ファイル | 最新の仕様 |
| `--research`, `-r` | 調査結果ファイル | 自動検出 |
| `--template`, `-t` | 計画テンプレート | `default` |

## 例

### 基本的な計画生成

```bash
$ speckit plan
仕様を分析中: .specify/specs/001-user-auth/spec.md
調査結果を読み込み中: .specify/specs/001-user-auth/research.md

技術計画を生成中...
✓ 計画を生成しました: .specify/specs/001-user-auth/plan.md
```

### 特定の仕様を指定

```bash
$ speckit plan --spec .specify/specs/002-profile/spec.md
✓ 計画を生成しました
```

## 生成される計画の内容

### 1. 技術スタック
```markdown
## 技術スタック
- フロントエンド: React + TypeScript
- バックエンド: Node.js + Express
- データベース: PostgreSQL
- 認証: JWT + bcrypt
```

### 2. アーキテクチャ
```markdown
## アーキテクチャ
- レイヤードアーキテクチャ
- コントローラー → サービス → リポジトリ
```

### 3. ファイル構造
```markdown
## ファイル構造
src/
├── controllers/
│   └── authController.ts
├── services/
│   └── authService.ts
├── repositories/
│   └── userRepository.ts
└── models/
    └── User.ts
```

## 関連コマンド

- `research` - 技術調査を実行
- `tasks` - 計画からタスクを分解
- `implement` - 計画に基づいて実装
