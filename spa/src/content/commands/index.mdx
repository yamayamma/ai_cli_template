# コマンドリファレンス

SpecKitは、仕様駆動開発（SDD）のワークフローをサポートする一連のCLIコマンドを提供します。

## コマンドカテゴリ

### 仕様管理
- **specify** - 新しい機能仕様を作成
- **clarify** - 仕様の曖昧な部分を明確化

### 計画・設計
- **research** - 技術調査を実行
- **plan** - 実装計画を生成
- **tasks** - タスク分解を作成

### 実装・検証
- **implement** - 仕様に基づいて実装
- **verify** - 実装が仕様を満たすか検証

## クイックスタート

```bash
# 新しい機能仕様を作成
speckit specify "ユーザー認証機能"

# 仕様を確認・明確化
speckit clarify

# 技術計画を生成
speckit plan

# 実装を開始
speckit implement
```

詳細は各コマンドのページを参照してください。
