# clarify コマンド

既存の仕様の曖昧な部分を特定し、明確化します。

## 概要

`clarify` コマンドは、仕様ドキュメントを分析し、曖昧な表現や不足している情報を特定します。
AIとの対話を通じて、仕様をより明確で実装可能な状態に改善します。

## 構文

```bash
speckit clarify [spec-path] [options]
```

## オプション

| オプション | 説明 | デフォルト |
|-----------|------|----------|
| `--auto`, `-a` | 自動的に明確化を提案 | `false` |
| `--spec`, `-s` | 対象の仕様ファイル | 最新の仕様 |
| `--output`, `-o` | 出力先 | 元のファイル |

## 例

### 最新の仕様を明確化

```bash
$ speckit clarify
分析中: .specify/specs/001-user-auth/spec.md

発見された曖昧な点:
1. "適切なエラー処理" - 具体的なエラーケースが未定義
2. "セキュアな実装" - セキュリティ要件が不明確

? 1. のエラーケースを明確化しますか？ (Y/n)
```

### 自動モードで提案を生成

```bash
$ speckit clarify --auto
✓ 5件の曖昧な点を検出しました
✓ 明確化の提案を生成しました

提案:
- "適切なエラー処理" → 以下のエラーケースを処理:
  - 無効な認証情報
  - セッション期限切れ
  - ネットワークエラー
```

## 検出される曖昧さの種類

1. **主観的な表現** - "適切な", "十分な", "高速な" など
2. **未定義の用語** - 定義されていない専門用語
3. **欠落した詳細** - エッジケース、エラー処理など
4. **矛盾** - 仕様内の矛盾する記述

## 関連コマンド

- `specify` - 新しい仕様を作成
- `plan` - 明確化された仕様から計画を生成
