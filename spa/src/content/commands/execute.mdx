# execute コマンド

タスク計画に基づいて実装を段階的に実行します。

## 概要

`execute` コマンドは、`tasks` コマンドで生成されたタスクリストに従って、
順序立てて実装を進めます。各タスクの完了状態を追跡し、進捗を管理します。

## 構文

```bash
speckit execute [options]
```

## オプション

| オプション | 説明 | デフォルト |
|-----------|------|----------|
| `--task`, `-t` | 特定のタスクを実行 | 次の未完了タスク |
| `--all`, `-a` | 全タスクを連続実行 | `false` |
| `--dry-run` | 実行せず計画のみ表示 | `false` |

## 例

### 次のタスクを実行

```bash
$ speckit execute
現在のタスク: T003 - UserServiceクラスを作成

実行中...
✓ src/services/userService.ts を作成しました
✓ テストを実行しました: 3/3 passed

タスクT003を完了としてマークしますか？ (Y/n)
```

### 特定のタスクを実行

```bash
$ speckit execute --task T005
タスク T005: ログインAPIエンドポイントを実装

実行中...
✓ src/controllers/authController.ts を更新しました
✓ src/routes/auth.ts を作成しました
```

### ドライラン（実行プレビュー）

```bash
$ speckit execute --dry-run
実行予定のタスク: T003 - UserServiceクラスを作成

予定される変更:
- 新規ファイル: src/services/userService.ts
- 新規ファイル: tests/services/userService.test.ts

実際に実行するには --dry-run を外してください
```

## 実行フロー

1. **タスク選択** - 次の未完了タスクを特定
2. **コンテキスト準備** - 関連ファイルと仕様を読み込み
3. **実装** - AIが仕様に基づいてコードを生成
4. **検証** - テストを実行して正しさを確認
5. **完了マーク** - タスクを完了として記録

## 関連コマンド

- `tasks` - タスクリストを生成
- `verify` - 実装を検証
- `plan` - 実装計画を確認
