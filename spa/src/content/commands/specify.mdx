# specify コマンド

新しい機能やタスクの仕様を作成します。

## 概要

`specify` コマンドは、ユーザーの入力や対話を通じて、構造化された仕様ドキュメントを生成します。
生成された仕様は `.specify/` ディレクトリに保存され、後続のコマンドで参照されます。

## 構文

```bash
speckit specify [feature-name] [options]
```

## オプション

| オプション | 説明 | デフォルト |
|-----------|------|----------|
| `--interactive`, `-i` | 対話モードで仕様を作成 | `true` |
| `--template`, `-t` | 使用するテンプレート | `default` |
| `--output`, `-o` | 出力先ディレクトリ | `.specify/` |

## 例

### 基本的な使用

```bash
$ speckit specify "ユーザー認証機能"
✓ 仕様ファイルを作成しました: .specify/specs/001-user-auth/spec.md
```

### 対話モードで詳細な仕様を作成

```bash
$ speckit specify --interactive
? 機能名を入力してください: ユーザープロフィール編集
? 主要な要件は何ですか？: ユーザーが自分のプロフィール情報を編集できる
? 受け入れ基準を入力してください: プロフィール画像、表示名、自己紹介を変更可能
✓ 仕様ファイルを作成しました
```

### テンプレートを指定

```bash
$ speckit specify "API エンドポイント" --template api
✓ API仕様テンプレートを使用しました
```

## 出力

生成される仕様には以下が含まれます：

- **概要** - 機能の簡潔な説明
- **背景** - なぜこの機能が必要か
- **要件** - 機能要件の一覧
- **受け入れ基準** - 完了の定義
- **制約事項** - 技術的・ビジネス的制約

## 関連コマンド

- `clarify` - 仕様の曖昧な部分を明確化
- `research` - 仕様に基づいて技術調査を実行
