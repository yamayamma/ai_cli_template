# SpecKit Documentation

AIと協調して開発を進める、**Spec Driven Development（SDD）**のためのツールキットです。

## SpecKitとは

SpecKitは、仕様書を起点として開発を進めるための開発支援ツールです。
AIとの協調により、仕様の明確化から実装、検証まで一貫したプロセスで開発を進めることができます。

## 主な特徴

- **仕様駆動**: 仕様書ファーストの開発アプローチ
- **AI協調**: 各ステップでAIがサポート
- **TDD重視**: テスト駆動開発による品質担保
- **自動化**: ドキュメント生成やタスク管理の自動化
