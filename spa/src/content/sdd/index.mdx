# Spec Driven Development

仕様書を起点として開発を進める、AIとの協調による開発アプローチです。

## SDDの特徴

- **仕様ファースト**: コードより先に仕様を明確にする
- **AI協調**: 開発プロセス全体をAIがサポート
- **TDD重視**: テスト駆動開発による品質担保
