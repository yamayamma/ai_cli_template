## Common Moves

- Editorial/product framing: eyebrow label, focused H1, short lead, then immediate artifact.
- GitHub-like dark system: deep background, raised panels, muted gray borders, blue accents, and semantic status colors.
- Purpose-built visuals: inline SVG, miniature UI mockups, charts, timelines, matrices, code blocks, and live controls.
- Dense scanning: chips, metadata rows, compact cards, tables, sidebars, and numbered sections.
- Self-contained delivery: no external build step, no remote asset dependency, plain JavaScript when behavior is needed.
